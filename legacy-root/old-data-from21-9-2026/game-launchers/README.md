# Archived Local Game Launchers

Ba adapter cũ từng được Toolstart trong repo mạng xã hội dùng để khởi động game từ repo sibling `game-hoanhao`. Chúng được lưu để tham khảo lịch sử, không còn là service của `hoan-hao` và không được Toolstart mạng xã hội đăng ký nữa. Mã gameplay và asset vẫn ở repo `game-hoanhao`.
